# Live Chat Q&A — Roman Hindi

## 1. Viewer: Main backend development mein beginner hoon. Samajh nahi aa raha kahan se shuru karun.

**His answer:**

"Nirdisht karke batao kya nahi kar paa rahe ho. Backend samajh nahi aa raha, projects nahi ban rahe, ya koi aur dikkat hai? Aisi vague request se main bhi kuch nahi kar paunga aur tum bhi kuch nahi kar paoge.

Pehle focus karo, achhe se seekho aur kam se kam 3-4 challenging projects banao. Uske baad job search shuru karo. Ecosystem mein active rehna bhi zaroori hai."

## 2. Viewer: Main job ke liye apply kar raha hoon, lekin kahin se response nahi aa raha.

**His answer:**

"Sabse pehle apne projects dekho. Aap randomly apply kar rahe ho ya cold emails bhej rahe ho? Community mein active ho? LinkedIn par connections bana rahe ho?

Ye koi one-shot cheez nahi hai. Aapko ecosystem mein active rehna padega. Conferences, communities, Twitter Spaces, LinkedIn — in sab jagah logon se connect karo."

## 3. Viewer: AI Engineer banna hai. Kya backend seekhna zaroori hai?

**His answer:**

"Bilkul. Aapko Express ya FastAPI jaise frameworks ka understanding hona chahiye. API kaise kaam karti hai, API calls kaise karte hain, data formats aur JSON kya hota hai — ye sab samajhna zaroori hai.

Aakhir mein aapko AI model ko kisi application ke saath connect hi karna hai."

## 4. Viewer: Express seekhun ya NestJS?

**His answer:**

"Express achhe se seekh lo. NestJS mein aapko bahut saari cheezein familiar lagenगी. Framework basically aapko ek structure deta hai — files kahan rakhni hain, kya karna hai aur kya nahi karna hai.

Concept samajh aa gaya toh framework samajhna itna mushkil nahi hota."

## 5. Viewer: Software Architect exactly karta kya hai?

**His answer:**

"Software architect ka kaam poore system ko dekhna hai. Koi na koi toh decide karega ki Postgres use karna hai ya MongoDB, AWS jaana hai ya DigitalOcean, caching kaise karni hai.

Ye sirf web development tak limited nahi hai. Software ko software ki tarah dekhiye, sirf web ya mobile application ki tarah nahi."

## 6. Viewer: Main first year mein hoon aur itni saari technologies dekh kar overwhelmed feel karta hoon.

**His answer:**

"Overwhelmed feel hona buri baat nahi hai. Aapko ab samajh aa raha hai ki field kitni badi hai.

Ek language choose karo — JavaScript ya Python. Uske fundamentals samjho, phir uski libraries aur frameworks explore karo. Aur projects banao. Ek saath sab kuch seekhne ki zaroorat nahi hai."

## 7. Viewer: Vibe coding karna sahi hai ya pehle sab kuch khud seekhna chahiye?

**His answer:**

"Main vibe coding ke against nahi hoon. Main khud use karta hoon. Agar aapko usse kuch naya seekhne ka spark mil raha hai toh bilkul karo.

Lekin jab aap atakte ho, toh fundamentals samajhna zaroori hai. AI har jagah aapki problem solve nahi kar paayega. Aapko khud bhi samajhna padega ki code mein ho kya raha hai."

## 8. Viewer: Quantitative Engineering mein career banana hai. Kya roadmap follow karun?

**His answer:**

"Honestly, mujhe iske baare mein zero idea hai. Main bina jaane aapko koi roadmap de doon, uska koi fayda nahi hai.

Mujhe khud nahi pata ki is field mein exactly kya karna hota hai."
